# 薪跳 PayPulse

> 每一秒，都在為你入帳。

即時顯示「今天已經賺了多少錢」的上班鼓勵器。純前端單一頁面，所有資料只存在瀏覽器 localStorage。

## 功能

- **今日已入帳**：依月薪／時薪與工時，每秒即時跳動，精確到小數點後四位
- **距離下班倒數**、今日工時進度（午休可設定是否計薪）
- **本月累計**：已過工作日按滿勤計
- **今日戰利品**：賺回一杯珍奶、一個便當、一張電影票……還要上班多久
- **帶薪摸魚**：計算摸魚時段賺到的錢
- **老闆鍵**（按 `B`）：模糊所有金額，分頁標題也會偽裝
- 下班瞬間彩帶慶祝、支援 TWD / HKD / MOP / CNY / USD / GBP / EUR / CAD / AUD / SGD / JPY
- **中英雙語**：右上角「中／EN」切換並記住選擇。預設語言依序看網址的 `?lang=`、自己選過的、IP 地區（台灣、香港、澳門、中國用中文，其他用英文；`functions/index.js` 在 Cloudflare 寫進 `<html data-geo>`）、瀏覽器語言。英文版第一次打開預設美元、09:00–17:30、午休 30 分鐘不計薪

## 本地預覽

```bash
python3 -m http.server 8765
```

然後打開 http://localhost:8765
